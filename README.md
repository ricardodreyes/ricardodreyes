**Outside of work:** lifting, and keeping tabs on San Francisco, which is where two of the projects below came from.
## Selected work
- [Giraux Shopify and media platform](https://ricardoreyes.dev/giraux-media). Employment work spanning Liquid themes, booking and product media. I built the NetSuite-to-Shopify pipeline for a historical import of 849 products and 859 variants and migrated 476,851 media files to Cloudflare Workers and R2. The historical spin-viewer comparison showed 97% less page weight. Production code belongs to Giraux.
- [SF Muni Equity Tracker](https://github.com/ricardodreyes/sf-muni-equity): An analysis of 28.7 million modeled delay observations joined to census tract income. Routes through the poorest tracts average 2.6 times the delay of the richest. Most of that gap is 3 cable cars, though. [Live map](https://sf-muni-equity.vercel.app).
- [SF Accountability Ledger](https://github.com/ricardodreyes/sf-equity-tracker): 12 reporting deadlines San Francisco wrote into its own laws, assessed against primary sources. It scores filed and findable separately. Recurring checks are paused.
- [gtm-warehouse](https://github.com/ricardodreyes/gtm-warehouse): a dbt warehouse on DuckDB over my own cold outreach data. SCD type 2 lead history, a late-arriving reply fact, 76 data tests, and a synthetic dataset so anyone can run it.
- [aidep](https://github.com/aidep-dev/aidep): Dependabot for AI APIs. Finds deprecated model and API usage in a repo and opens the migration PR.
